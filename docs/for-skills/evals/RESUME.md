## 課題を流し直す

会話の作業用のフォルダーは会話ごとに消えるので、次を作り直す。

| 作るもの | 作り方 |
|----------|--------|
| スキルの写し B | `git archive f1ff4e4 .claude/skills/sustainable-code-jp \| tar -x -C <作業>/skills/B --strip-components=3` |
| スキルの写し C | 同じく、コミット `cc780aa` から |
| スキルの写し D | C の写しの SKILL.md を results/skill-D/SKILL.md に置き換える（S11〜S13 を入れたもの） |
| 作業フォルダー | 課題ごと・条件ごと（・回ごと）の空のフォルダーに tasks/ の課題の文を写す。T6 は task.md と run_tests.sh を写す |
| 伏せた名前 | `<作業>/blind/<課題>/X1〜X4` を、作業フォルダーへのシンボリック リンクにし、対応を mapping.json に書く |

- ワークフローの台本は results/workflows/ にある（`args` に `sp`（作業のフォルダー）と `repo`（リポジトリ）を渡す）。被験者への指示の文と、判定者への指示の文は、この台本のとおりに使うと、これまでの結果と比べられる。
- スキルのファイルは、写しだけを変える。リポジトリの `.claude/skills/` は変えない。

## results/ の中身

| ファイル | 中身 |
|----------|------|
| run/<課題>-<条件>[-r<回>]/answer.md | 被験者の出力（1 回目は回の番号なし）。T6 は test-log.txt と .py も |
| mapping.json | 判定者に見せた名前（X1〜X4）と条件（A〜D）の対応 |
| judgements.json | 判定者の返した合否、確信、理由、注（first-32、repeat-40） |
| skill-D/SKILL.md | 条件 D のスキルの SKILL.md（references は C と同じ） |
| workflows/*.js | 流したワークフローの台本 |
