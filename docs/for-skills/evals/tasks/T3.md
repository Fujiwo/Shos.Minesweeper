# 課題 T3: クラス設計のレビュー

次は、マインスイーパーのクラス設計書の一部である。`Shos.Minesweeper.Presentation` は、Web 版・デスクトップ版・コンソール版の 3 つのアプリが共有するクラスライブラリで、`BoardCursor` はその公開の型である。

```csharp
namespace Shos.Minesweeper.Presentation;

/// キーボードで選んでいるマス（カーソル）。3 つの版が使う。
public sealed class BoardCursor
{
    public CellPosition Position { get; private set; }

    /// 矢印キーで 1 マス動かす。盤面の端では止まる。
    public void Move(Direction direction, Board board) { /* 端の判定は board.Contains を使う */ }

    /// マウスで選んだマスなど、指定の位置へ動かす。
    public void MoveTo(CellPosition position, Board board) => Position = position;
}
```

設計書の説明: 「`MoveTo` に渡すのは、画面で押されたマスの位置だけで、呼ぶ側が盤面の中の位置しか渡さない。そのため、盤面の中かを確かめるガード節は置かない（引き算）。」

この設計をレビューし、指摘があれば、指摘と直し方を示せ。指摘がなければ、そう書け。
