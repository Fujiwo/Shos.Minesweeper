# 課題 T2: ビューモデルの変化の通知

C# と Avalonia UI 12 で、マインスイーパーのデスクトップ版を作る。MVVM の支援ライブラリ（CommunityToolkit.Mvvm、ReactiveUI など）は使わないと決めている。

ビューモデルは 5 つある: `GameViewModel`、`BoardViewModel`、`CellViewModel`、`DifficultyDialogViewModel`、`WinCardViewModel`。どれも `INotifyPropertyChanged` を実装して、プロパティの変化を View に知らせる。

5 つのビューモデルでの変化の通知の書き方を設計せよ。型の構成と、1 つのビューモデルの例（プロパティ 1〜2 つ）のコードを示し、そう決めた理由を書け。
