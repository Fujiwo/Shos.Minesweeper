# 課題 T8: 不具合の修正

C# と Avalonia UI 12.1 で作ったデスクトップ版マインスイーパー（Windows 11）で、次の不具合が見つかった。

- 盤面、残り地雷数、経過時間の表示は、どれも `Border` の中に `TextBlock` などを入れて作っている。読み上げの名前は、各 `Border` に `AutomationProperties.Name` で付けている。
- Windows の UI オートメーションの木（Inspect.exe などで見る）に、この名前が出ない。スクリーン リーダーも読み上げない。
- ビューモデルのテストは Green である。画面のテスト（Avalonia.Headless）は、このプロジェクトでは使えない。

あなたはこのアプリを手元で動かせない。直すための進め方と、直し方（コードの変更）を決めて示せ。調べたことがあれば、その内容と出どころも書け。
