# 課題 T4: コードレビュー

次は、Avalonia UI のデスクトップ版マインスイーパーで、マスを開いたときの演出を行うコードである。開いたマスの「覆い」を、近いマスから順に消していく。テストは Green で、画面でも演出が見えた。

```csharp
public sealed class BoardView : UserControl
{
    readonly Dictionary<CellPosition, CellView> cellViews = new();

    public void Show(MoveResult move, bool withAnimation)
    {
        foreach (var cell in move.ChangedCells)
            cellViews[cell.Position].Update(cell);

        if (withAnimation)
            _ = PlayOpeningAsync(move.OpenedCells);
    }

    async Task PlayOpeningAsync(IReadOnlyList<CellPosition> opened)
    {
        foreach (var (position, delay) in ViewAnimations.OpeningOrderOf(opened)) {
            await Task.Delay(delay);
            var view = cellViews[position];
            await view.Cover.FadeOutAsync(TimeSpan.FromMilliseconds(120));
            view.Cover.IsVisible = false;
        }
    }
}
```
