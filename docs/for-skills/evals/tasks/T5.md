# 課題 T5: 変更のレビュー

Blazor WebAssembly（スタンドアロン。静的サイトとして公開し、すべてブラウザーの中で動く）のマインスイーパーに、次の変更が出された。利用者が入力した文字列（カスタムの盤面の幅など）を、解釈する前に整える。全角の「３０」を受け付けるためである。

```csharp
// Shos.Minesweeper.Presentation（Web 版とデスクトップ版が共有するクラスライブラリ）
public static class InputText
{
    public static string Normalize(string text) => text.Trim().Normalize(NormalizationForm.FormKC);
}
```

```csharp
// Shos.Minesweeper.Presentation.Tests（xUnit。PC の .NET 10 で dotnet test で動く）
public class InputTextTests
{
    [Theory]
    [InlineData("３０", "30")]
    [InlineData(" 16 ", "16")]
    [InlineData("１６", "16")]
    public void NormalizesFullWidthDigitsAndTrims(string input, string expected)
        => Assert.Equal(expected, InputText.Normalize(input));
}
```

作者の説明: 「テストを先に書き、Red を見てから実装した。全テストが Green。」

この変更を、取り込む前にレビューせよ。指摘ごとに、問題と、取り込む前にすべきことを書け。
