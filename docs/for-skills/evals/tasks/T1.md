# 課題 T1: コンソール版の画面の設計

C# と .NET 10 で、マインスイーパーのコンソール版を作る。Windows 11 と Linux の端末で動かす。ライブラリは使わず、`System.Console` と VT のシーケンス（エスケープ シーケンス）だけで描く。

- 画面は 3 つある: ゲームの画面、難易度を選ぶ画面、ヘルプの画面。キーで画面を行き来する。
- ゲームのルールは、別のクラスライブラリ（`Board`、`Game` など。テスト済み）にある。
- 画面の単位は、xUnit で単体テストしたい。端末が小さすぎるときは、「端末を大きくしてください」という画面を出す。

このコンソール版の、画面まわりの型の設計（型の名前、主なメソッドのシグネチャ、責務、型の間の関係）を決めて示せ。コードの全体は書かなくてよい。設計の理由と、作らないことにしたものがあればそれも書け。
