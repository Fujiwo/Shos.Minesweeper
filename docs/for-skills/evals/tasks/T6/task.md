# 課題 T6: テストファーストで 4 つの型を作る

このフォルダーの中で、Python 3 の標準の `unittest` を使って、マインスイーパーの次の 4 つの型をテストファーストで作れ。外部のパッケージは使わない。

| 型 | ファイル | 仕様 |
|----|----------|------|
| `CellPosition` | `cell_position.py` | 列と行（0 以上の整数）を持つ。等しさは列と行で決まる。`neighbors(columns, rows)` は、盤面（列の数、行の数）の中にある周りのマス（最大 8）を返す |
| `BoardSize` | `board_size.py` | 列の数と行の数と地雷の数を持つ。列と行は 5〜30、地雷は 1 以上で、マスの数より 1 つ以上少ない。範囲の外は `ValueError` |
| `FlagCounter` | `flag_counter.py` | 地雷の数から、立てた旗の数を引いた「残りの地雷の数」を返す。旗が地雷の数を超えると負になる |
| `ElapsedTime` | `elapsed_time.py` | 経過した秒を、999 で止めて 3 桁の文字列（`"007"` など）にする |

- テストは `test_*.py` に書く。
- テストを流すときは、必ず `./run_tests.sh` を使うこと（`python -m unittest` を直接呼ばない）。流すたびに、そのときのファイルと結果が `test-log.txt` に記録される。
- 最後に、全テストが通ることを確かめて報告せよ。
