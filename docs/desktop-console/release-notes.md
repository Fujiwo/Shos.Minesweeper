# リリースノート（デスクトップ版・コンソール版）

デスクトップ版とコンソール版は、版番号をそれぞれ別に付けます（Web 版の版番号とも別です）。各版の節は、GitHub Releases のその版の説明にもなります。Web 版のリリースノートは docs/release-notes.md にあります。

## デスクトップ版 1.0.0（公開前）

Windows で遊べるマインスイーパーの、デスクトップ アプリの最初の版です。ブラウザー版（https://fujiwo.github.io/Shos.Minesweeper/ ）と同じゲームを、1 つのウィンドウで遊べます。

### 動かし方

1. この Release の `Shos.Minesweeper.Desktop-1.0.0-win-x64.zip` をダウンロードし、展開します。
2. 展開した `Shos.Minesweeper.Desktop.exe` を開きます。インストールは要りません。.NET を入れる必要もありません。
3. 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。このアプリには署名をしていないため、この確認が出ます。

- 動作環境: Windows 11（x64）。
- 実行ファイルは約 100MB です。初めて開くときは、準備のために少し時間がかかることがあります。

### 遊べること

- 難易度: 初級（9×9、地雷 10）、中級（16×16、地雷 40）、上級（30×16、地雷 99）、カスタム（幅 5〜30、高さ 5〜24、地雷 1〜「幅×高さ − 9」）。
- 最初に開いたマスとその周りには、地雷がありません。
- 開いた数字のマスを押すと、周りの旗の数が数字と同じときに、残りのマスをまとめて開きます（コード）。
- 初級・中級・上級のベストタイムを記録します。
- マスを開いたときなどに効果音が鳴り、開いたマスが広がる、地雷が現れるなどの動きがあります。音も動きも、ブラウザー版と同じです。
- ウィンドウの大きさを変えると、マスの大きさが合います。難易度を変えると、ウィンドウが盤面に合った大きさになります。

### 操作

| 操作 | マウス | キーボード |
|------|--------|------------|
| マスを開く | 左クリック | 矢印キーでマスを選び、Space か Enter |
| 旗を立てる・外す | 右クリック | F |
| 新しいゲーム | 顔のボタン | F2 |
| 難易度を変える | 左上の難易度のボタン | Tab でボタンに移り、Enter |
| 効果音を消す・戻す | 右上のスピーカーのボタン | Tab でボタンに移り、Space |

- タッチの画面でも、タップで開けます。旗を立てるには、右クリックに当たる操作か F キーを使います（タッチでの長押しの旗はありません）。

### 知っておいてほしいこと

- ベストタイムと効果音の設定は、`%LOCALAPPDATA%\Shos.Minesweeper\Desktop` に保存します。コンソール版の記録とは別です。インターネットには何も送りません。
- 効果音の音量は、Windows の音量に従います。
- Windows の「アニメーション効果」（設定 → アクセシビリティ → 視覚効果）をオフにしていると、動きを止めて、結果をすぐに表示します。
- ナレーターで、マスの位置と状態、ツールバーの各要素、勝敗が読み上げられます。盤面を表（行と列）として読み上げることには、まだ対応していません。
- Windows 10 と Arm の Windows では確かめていません。

## コンソール版 1.0.0（公開前）

端末（コマンド プロンプト、Windows Terminal、Linux の端末）の中で遊べるマインスイーパーの、最初の版です。キーボードだけで遊びます。

### 動かし方

Windows:

1. この Release の `Shos.Minesweeper.ConsoleApp-1.0.0-win-x64.zip` をダウンロードし、展開します。
2. Windows Terminal かコマンド プロンプトで、展開したフォルダーに移り、`Shos.Minesweeper.ConsoleApp.exe` を実行します。
3. 初めて開くときに「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。このアプリには署名をしていないため、この確認が出ます。

Linux:

1. この Release の `Shos.Minesweeper.ConsoleApp-1.0.0-linux-x64.tar.gz` をダウンロードし、`tar -xzf Shos.Minesweeper.ConsoleApp-1.0.0-linux-x64.tar.gz` で展開します。
2. `./Shos.Minesweeper.ConsoleApp` で実行します。「許可がありません」と出たら、`chmod +x Shos.Minesweeper.ConsoleApp` をしてから実行し直します。
3. 起動できないときは、ICU のライブラリ（Ubuntu・Debian では `libicu` で始まるパッケージ）を入れてください。多くの Linux には初めから入っています。

- 動作環境: Windows 11（x64）の Windows Terminal とコマンド プロンプト、Linux（x64）。Linux は WSL の Ubuntu で確かめています。
- インストールは要りません。.NET を入れる必要もありません。
- 端末の大きさは、80 列 × 24 行以上にしてください。

### 遊べること

- 難易度、最初のマス、コード、ベストタイムは、デスクトップ版と同じです。
- 盤面は記号で表します（`#` 開いていない、`F` 旗、数字、`*` 地雷、`@` 踏んだ地雷、`X` 誤った旗）。選んでいるマスは `[ ]` で囲み、色を反転します。
- 効果音と動きはありません。

### 操作

| キー | 動作 |
|------|------|
| 矢印キー、または H・J・K・L | マスを選ぶ（H 左、J 下、K 上、L 右） |
| Space または Enter | 選んだマスを開く（数字のマスならコード） |
| F | 旗を立てる・外す |
| N | 新しいゲーム |
| D | 難易度を選ぶ（1〜4 のキー、または矢印と Enter） |
| ? | キーの一覧 |
| Q、Ctrl+C | 終わる |

- 英字のキーは、大文字でも小文字でも効きます。日本語の入力がオンのままでも、数字と「？」は効きます。

### 知っておいてほしいこと

- ベストタイムは、Windows では `%LOCALAPPDATA%\Shos.Minesweeper\ConsoleApp`、Linux では `~/.local/share/Shos.Minesweeper/ConsoleApp` に保存します。デスクトップ版の記録とは別です。インターネットには何も送りません。
- 端末が盤面より小さいときは、盤面の代わりに、要る大きさを知らせます。端末を広げると続きから遊べます。そのときは、D で小さい難易度を選ぶこともできます（端末の幅は、どの画面も 76 列が要ります）。カスタムの最大（30×24）は、24 行の端末には収まりません。
- 環境変数 `NO_COLOR` を設定すると、色を付けずに表示します。
- 終わるときは、端末を元の画面と状態に戻します。
