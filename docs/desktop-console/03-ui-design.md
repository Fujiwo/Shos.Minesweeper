## 1. 概要

仕様書で決めた操作と表示を、デスクトップ版のウィンドウとコンソール版の端末の画面に落とし込む。この文書は「どう見えるか」を定める。実現の方法（Avalonia のコントロールの分け方、端末への書き方）は、アーキテクチャー設計書以降で決める。

### 1.1 デザインの方針

| 方針 | デスクトップ版 | コンソール版 |
|------|----------------|--------------|
| Web 版と同じ見た目 | **Web 版の UI デザイン（1.1.0 の 10 章を含む）の配色、形、アイコン、文言、効果音、演出をそのまま使う。** この文書では、ウィンドウに合わせて変える点だけを定める | 文言と、盤面の情報の出し方（残り地雷数、経過時間、勝敗の知らせ）を Web 版にそろえる。見た目は端末の升目に合わせて決め直す |
| 盤面を最大に | ツールバーを 1 本にし、盤面にウィンドウを合わせる（仕様書 4.4） | 上級の盤面と表示を、80 列×24 行に収める（仕様書 5.5） |
| 色だけに頼らない | Web 版と同じ（形と文字でも区別する） | 記号と角かっこで区別し、色がなくても遊べるようにする（仕様書 5.4、5.6） |
| どの環境でも同じ見た目 | アイコンは Web 版の SVG と同じ形のベクターで描く。拡大率が変わってもぼやけない | ASCII の文字だけで盤面を描く。幅があいまいな文字（×、■、● など）は、盤面にも文言にも使わない（調査書 5.4） |

「Web 版の UI デザイン」の節を指すときは「Web 版 UI 2.3」のように書く。

## 2. デスクトップ版

### 2.1 要素の一覧

Web 版 UI 2.1 の要素から、旗モード ボタン（E）を除く。記号は Web 版と同じものを使う。

| 記号 | 要素 | Web 版からの違い |
|------|------|------------------|
| A | 難易度ボタン | なし |
| B | 残り地雷数 | なし |
| C | リセット ボタン | なし（顔のアイコンで状態を示す） |
| D | 経過時間 | なし |
| J | 効果音 ボタン | なし |
| F | 盤面 | 旗モードの縞模様がない。縦と横を入れ替えない |
| G | 難易度ダイアログ | ウィンドウの中に重ねて出す（2.5） |
| H | 勝利カード | なし（置き方も Web 版 UI 10.5 のまま） |
| I | 読み上げの領域 | 画面には表示しない。UI オートメーションのライブ リージョン（仕様書 4.8） |

ツールバーの要素は、左から A、B、C、D、J の順に並べる。

### 2.2 ウィンドウ

| 項目 | 内容 |
|------|------|
| 題名 | 「マインスイーパー」 |
| 題名の帯 | OS の標準のものを使う（最小化、最大化、閉じる） |
| アプリのアイコン | Web 版の地雷のアイコン（Web 版 UI 4.4）から作る |
| 背景 | `page` の色（Web 版 UI 4.1） |
| 最小の大きさ | 中身の領域で 400×320（ツールバーが 1 本に収まり、初級の盤面が下限のマスで収まる大きさ） |
| 右クリックのメニュー | 出さない（仕様書 4.3） |

#### 中身の配置

- ツールバーと盤面のまとまりを、ウィンドウの中身の領域の中央に置く（Web 版 UI 10.4 の上バーと同じ）。ツールバーは盤面のすぐ上（間 4px）に付ける。
- まとまりの周りに、16px の余白を置く。
- ツールバーの幅は、「中身の領域の幅 − 32px」と 480px の小さいほうにする（Web 版 UI 3.1 と同じ上限）。
- 盤面の領域は、中身の領域から、余白（上下左右 16px）とツールバーの高さ（52px）と間（4px）を引いた大きさとする。

#### マスの大きさとウィンドウの大きさ（仕様書 4.4）

| 場面 | 決め方 |
|------|--------|
| 起動したとき、難易度を変えたとき | マスを**既定の 32px** にしたときに盤面とツールバーが収まる大きさに、ウィンドウの中身を合わせる。画面の作業領域に収まらないときは、収まる最大の大きさにし、マスはその中で決め直す（下の行） |
| 利用者がウィンドウの大きさを変えたとき、ウィンドウを最大化したとき | 盤面の領域に盤面が収まる最大の整数の大きさ（上限 48px、下限 20px）にマスを合わせる。下限でも収まらないときは、下限で表示し、盤面の領域をスクロールできるようにする |
| ウィンドウを最大化しているときに難易度を変えたとき | ウィンドウの大きさは変えず、マスの大きさだけを決め直す |

- 大きさの単位は、Windows の拡大率を掛ける前の大きさ（論理的な px）とする。
- 既定を 32px にするのは、上級のウィンドウを、よくある小さいノート PC の画面（1366×768、拡大率 100%。作業領域は約 1366×728）に収めるためである。上級の中身は、幅 30×32 + 6（盤面の枠）+ 32（余白）= 998px、高さ 16×32 + 6 + 52 + 4 + 32 = 606px で、題名の帯を足しても収まる。
- ウィンドウの大きさを決め直すときは、ウィンドウの左上の位置を保つ。大きくなって画面の作業領域からはみ出すときは、はみ出さない位置に動かす。
- カスタムの最大（30×24）は、既定の 32px では高さ 862px になり、多くの画面に収まらないので、画面に収まる大きさに縮める。
- 盤面の枠（3px）とマスの見た目は、Web 版 UI 4.2 と 10.2 のとおりとする。

### 2.4 ツールバー

- 寸法、並べ方、見た目は、Web 版 UI 2.2、10.2、10.3 の「400px 以上」の行のとおりとする。旗モード ボタンがないので、A、B、C、D、J の 5 つを均等の間隔で並べる。
- ウィンドウの最小の幅（2.2）では、ツールバーの幅は 368px になる。5 つの要素の幅の合計（72 + 64 + 44 + 64 + 44 = 288px）と帯の余白（12px）を引いた 68px を、4 つの間隔に分ける。
- マウスで指したときのツールチップは、Web 版 UI 2.2、10.3 と同じ（「難易度を変える」「新しいゲーム」「効果音（オン）」「効果音（オフ）」）。

### 2.5 難易度ダイアログ（G）

- 中身と動きは、Web 版 UI 2.3 のとおりとする（初級・中級・上級の行、ベストタイム、現在の難易度のチェック、カスタムの入力欄と範囲、誤りの示し方、「カスタムで始める」）。
- 別のウィンドウにはせず、Web 版と同じく、ウィンドウの中身の中央に重ねて出し、盤面の上に半透明の幕（黒、不透明度 45%）をかける。題名の帯のある別のウィンドウにすると、ほかのウィンドウの後ろに隠れることがあり、Web 版と見た目がそろわないからである。
- ダイアログの幅は、「中身の領域の幅 − 32px」と 400px の小さいほう。中身の領域に収まらないときは、ダイアログの中をスクロールさせる。
- 閉じ方は、× ボタン、Esc キー、幕の部分のクリック（Web 版と同じ）。
- カスタムの入力欄では、日本語の入力（IME）もそのまま使える。入力した文字列は、仕様書 3 章のとおり整えてから読む。

### 2.6 勝利カード（H）と敗北時の表示

- Web 版 UI 2.4 と 10.5 のとおりとする（内容、ベストタイムの行の出し分け、「もう一度」「閉じる」、置き場所、フォーカス、閉じ方）。
- ウィンドウを盤面に合わせた大きさ（2.2）では、盤面の下に余白がないので、カードは盤面の下の段に重なる（Web 版 UI 10.5 の「余白がなければ」の規則）。「閉じる」で盤面を見られる。
- 敗北時は、カードを出さない（Web 版 UI 2.4）。

### 2.7 配色、マス、数字、アイコン

- **配色**: Web 版 UI 4.1 と 10.2 のトークンと値をそのまま使う。OS のライト・ダークの設定に合わせて切り替え、OS の設定が変わったら、開いたまま切り替える（仕様書 4.5）。色の組み合わせが同じなので、Web 版のコントラスト比の表（Web 版 UI 4.1、10.2）がそのまま成り立つ。
- **マス**: Web 版 UI 4.2 と 10.2 のとおり（タイルの形、開いたマス、踏んだ地雷、誤った旗）。旗モードの縞模様は使わない。
- **数字の色**: Web 版 UI 4.3 のとおり（太字、マスの 60% の大きさ）。
- **アイコン**: Web 版 UI 4.4 の形を、同じ座標（24×24）のベクターで描く。長押しの進行に使うスコップのアイコンは使わない。
- **マスの状態の見本**: Web 版の見本（docs/images/cell-states.svg）と同じ見た目になる。

### 2.8 文字

- 書体は、日本語の字形がそろう **Yu Gothic UI** とする（Windows 11 に標準で入っている）。Yu Gothic UI が使えないときは、Meiryo UI を使う。どちらも使えないときは、OS の既定の書体に任せる。
  - 書体を名前で指定するのは、Avalonia が漢字を意図と違う言語の書体で表示することがあり、書体を並べても順に代わりを探さないことがあるためである（調査書 4.4）。どの書体を使ったかは、実装で確かめ、見本の写真で残す（5 章）。
- 数字（マスの数字、残り地雷数、経過時間）は、値が変わっても位置がずれないように、幅をそろえて表示する（Web 版 UI 4.5 の `tabular-nums` に当たる）。
- 大きさは、本文 16px、補足 14px、ツールバーの数字 20px の太字（Web 版と同じ）。

### 2.9 操作に対するフィードバック

| 場面 | 表示 | Web 版との違い |
|------|------|----------------|
| マウスの左ボタン（タッチ、ペン）で押している間 | Web 版 UI 5.1 の押下中の表示と、顔の「驚き」 | 長押しの成立で押下中を消す規則はない（長押しがない） |
| マウスで指したとき | Web 版 UI 5.6 のとおり（未開放と旗のマスを `cell-closed-hover`、ボタンを少し暗く） | タッチとペンでは指した表示をしない（Web 版と同じ） |
| 右クリックで旗を立てたとき | 旗が広がる（150 ミリ秒、Web 版 UI 5.2 の最後の段落） | なし |
| ボタンを押している間 | 95% に縮む（Web 版 UI 10.2） | なし |
| 勝利、敗北 | Web 版 UI 5.4、5.5 のとおり | 旗モードがない |

- 長押しの進行の円（Web 版 UI 5.2）と、旗モードの表示（Web 版 UI 5.3）は作らない（仕様書 4.3）。

### 2.10 効果音と演出

- **効果音**: Web 版 UI 10.6 の 6 つの音を、同じ合成の値で鳴らす（Presentation の効果音の部品を使う）。効果音 ボタン（J）は Web 版 UI 10.3 のとおり。オンに戻したときは鳴らさない。
- **演出**: Web 版 UI 10.7 の演出（マスが開く、0 の連鎖の波、負け、勝ち）を、同じ遅れと長さで見せる。
- **動きを減らす設定**: OS の「アニメーション効果」がオフのときは、Web 版 UI 5.7 の表の「動きを減らす設定」の列のとおりにする（長押しの円の行を除く）。効果音はこの設定と関係なく、効果音の設定だけに従う（Web 版と同じ）。

### 2.11 アクセシビリティ

#### 色だけに頼らない表現

Web 版 UI 6.1 の表から、旗モードの行を除いたもの。

#### キーボードのフォーカス

- ボタンと入力欄のフォーカスの枠、盤面のカーソルの二重の枠は、Web 版 UI 6.3 のとおりとする（`focus` と `focus-inner`）。
- Tab キーでの移動の順は、難易度ボタン → リセット ボタン → 効果音 ボタン → 盤面 とする（Web 版 UI 6.3 から旗モード ボタンを除いたもの）。
- 起動したときは、盤面にキーボードのフォーカスを置く。すぐに矢印キーで遊び始められるようにするためである。カーソルの枠は、キーを押すまで出さない（Web 版 UI 6.3 の「キーボードのフォーカスがあるときだけ表示する」と同じ考え方）。
- F2 は、どこにフォーカスがあっても効く。ただし、難易度ダイアログを開いている間は効かない（ダイアログの中にフォーカスを閉じ込めているため。Web 版 UI 6.3）。
- 勝利カードを出したとき、閉じたときのフォーカスの動きは、Web 版 UI 2.4 のとおり。

#### スクリーンリーダー（仕様書 4.8）

| 要素 | 名前・読み上げ |
|------|----------------|
| 盤面 | 表（Grid）として読ませられるなら、名前は「盤面、9 行 9 列」。表として読ませられないときも、この名前を付ける |
| マス | Web 版 UI 6.4 のとおり（「3 行 5 列、未開放」など）。行と列は盤面の向きのまま（入れ替えない） |
| 難易度ボタン | 「難易度、初級」 |
| 残り地雷数 | 「残り地雷 10」 |
| リセット ボタン | 「新しいゲーム」 |
| 経過時間 | 「経過時間 45 秒」。毎秒の読み上げはしない |
| 効果音 ボタン | 「効果音」と、オンかオフかの状態（トグル ボタンの状態として伝える） |

ライブ リージョン（`AutomationProperties.LiveSetting` を Polite にした、画面に見えない要素）で、Web 版 UI 6.4 の表と同じ文（勝利、敗北、新しいゲーム）を知らせる。

## 3. コンソール版

### 3.1 画面の構成

端末の代替画面の左上から、次の行を並べる（仕様書 5.2）。

| 行 | 内容 |
|----|------|
| 1 | 上の行: 難易度と盤面の大きさ、残り地雷数、経過時間 |
| 2 | 空行 |
| 3〜 | 盤面（上下の枠を含む） |
| 盤面の次 | 状態の行 |
| 最後 | キーの案内の行 |

- まとまりは端末の左上に置き、中央には寄せない。端末の大きさが変わっても、描く位置が変わらないようにするためである。
- 端末の文字のカーソル（点滅する棒）は、ゲームの画面では隠す。カスタムの値を入力している間だけ出す。

### 3.2 ワイヤーフレーム

上級（30×16）の例。1 マスは 2 升（空白 1 升と記号 1 升）で描く。

```text
上級 30x16   残り地雷  95   経過時間  37 秒

+-------------------------------------------------------------+
| # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # |
| # # 1 1 2 # # # # # # # # # # # # # # # # # # # # # # # # # |
| # # 1     1 F # # # # # # # # # # # # # # # # # # # # # # # |
| # # 2 1   1 2 #[#]# # # # # # # # # # # # # # # # # # # # # |
| # # # 1     1 # # # # # # # # # # # # # # # # # # # # # # # |
|                  ...（16 行）                               |
+-------------------------------------------------------------+

矢印/HJKL 移動  Space 開く  F 旗  N 新しいゲーム  D 難易度  ? ヘルプ  Q 終了
```

- 盤面の 1 行は、「`|`、マスごとに（空白 1 升 + 記号 1 升）、空白 1 升、`|`」で、幅は 2 × 列数 + 3 升になる。上級では 63 升である。
- 盤面の上下の枠は、「`+`、`-` を（2 × 列数 + 1）個、`+`」とする。
- 上の例の `[#]` がカーソル（3.4）である。
- 状態の行は、上の例では空である（盤面の下の枠の次の行。プレイ中で、知らせることがない）。

初級（9×9）の例:

```text
初級 9x9   残り地雷  10   経過時間   0 秒

+-------------------+
| # # # # # # # # # |
| # # # # # # # # # |
|[#]# # # # # # # # |
| # # # # # # # # # |
| # # # # # # # # # |
| # # # # # # # # # |
| # # # # # # # # # |
| # # # # # # # # # |
| # # # # # # # # # |
+-------------------+
マスを開くと始まります。
矢印/HJKL 移動  Space 開く  F 旗  N 新しいゲーム  D 難易度  ? ヘルプ  Q 終了
```

#### 必要な端末の大きさ

| 盤面 | 幅 | 高さ |
|------|----|------|
| 初級（9×9） | 76 列（キーの案内の行） | 15 行 |
| 中級（16×16） | 76 列 | 22 行 |
| 上級（30×16） | 76 列 | 22 行 |
| カスタムの最大（30×24） | 76 列 | 30 行 |

- 幅は、キーの案内の行（76 升）と盤面の幅（2 × 列数 + 3）の大きいほうである。カスタムの最大の幅 30 でも 63 升なので、どの盤面でも 76 列になる。
- 高さは、盤面の行数 + 6 行（上の行、空行、盤面の上下の枠 2 行、状態の行、キーの案内の行）である。盤面と状態の行の間には空行を置かない。カスタムの最大を、Windows Terminal の既定の 30 行に収めるためである。
- 初級・中級・上級は 80 列×24 行に収まる（仕様書 5.5）。カスタムの最大は 30 行が要るので、24 行の端末では 3.8 の知らせが出る。Windows Terminal の既定（120 列×30 行。調査書 5.5。出典未確認）にはちょうど収まる。

### 3.3 上の行

```text
上級 30x16   残り地雷  95   経過時間  37 秒
```

- 難易度の名前（Web 版と同じ「初級」「中級」「上級」「カスタム」）、空白 1 升、盤面の大きさ（「幅x高さ」。`x` は ASCII の小文字）。盤面の大きさの記号に「×」を使わないのは、幅があいまいな文字だからである（調査書 5.4）。
- 「残り地雷」と数（4 升で右にそろえる。マイナスは「-3」、4 文字の「-100」も 4 升に収まる）。
- 「経過時間」と秒数（3 升で右にそろえる）と「秒」。
- 要素の間は空白 3 升とする。

### 3.4 盤面の記号、色、カーソル

#### 記号と色（仕様書 5.4、5.6）

| マスの状態 | 記号 | 色（16 色） | 色がないとき |
|------------|------|-------------|--------------|
| 未開放 | `#` | 暗い灰（DarkGray） | 同じ記号 |
| 旗 | `F` | 赤（Red） | 同じ記号 |
| 開いたマス（0） | 空白 | — | 同じ |
| 開いたマス（1〜8） | `1`〜`8` | 下の表 | 同じ記号 |
| 地雷（敗北時） | `*` | 既定の文字色 | 同じ記号 |
| 踏んだ地雷 | `@` | 白（White）の文字、暗い赤（DarkRed）の背景 | 同じ記号 |
| 誤った旗（敗北時） | `X` | 黄（Yellow） | 同じ記号 |

| 数字 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|------|---|---|---|---|---|---|---|---|
| 色 | 青（Blue） | 緑（Green） | 赤（Red） | 紫（Magenta） | 茶（DarkYellow） | 水色（Cyan） | 既定の文字色 | 暗い灰（DarkGray） |

- 色合いは、Web 版の数字の色（Web 版 UI 4.3）に近づけた。4 の紺は、端末の暗い青が黒い背景で読みにくいので、Web 版のダークの配色（紫寄り）に合わせて紫にした。5 のえんじは、クラシックの配色の起こり（茶）に近い DarkYellow にした。7 の黒は、背景が黒い端末で見えないので、既定の文字色にした。
- 16 色が実際にどの色で見えるかは端末の配色で決まり、コントラスト比は保証しない（仕様書 5.6）。Windows Terminal の既定の配色（Campbell）と、明るい配色の両方で見て、読みにくい色があれば実機で調整する。
- 記号はどれも ASCII の文字で、1 升を占める（仕様書 5.4）。旗の `F` は、旗を立てるキー（F）とそろえた。
- 勝利時に自動で立てた旗も `F` にする（Web 版 UI 4.2 と同じく、区別しない）。

#### カーソル

- カーソルのマスは、記号の左右の升に角かっこ（`[` と `]`）を置いて示す（3.2 の例）。マスの前の空白 1 升に `[` を、次のマスの前の空白 1 升（右端の列では枠の前の空白）に `]` を描く。色がなくても分かる。
- 色を付けるときは、カーソルのマスの記号を反転表示（文字と背景の色を入れ替える）にもする。
- カーソルは、キーを押す前から表示する。コンソール版はキーボードだけで遊ぶので、いつもカーソルの位置が要る。
- 勝敗が決まった後も、カーソルは表示したままにする（盤面を見て回れる）。

### 3.5 状態の行

| 場面 | 表示 |
|------|------|
| 未開始 | 「マスを開くと始まります。」 |
| プレイ中 | 空（入力の誤りなどの知らせがあるときだけ出す） |
| 勝利 | 読み上げの文（Web 版 UI 6.4）と同じ文に、「N で新しいゲーム。」を続ける。例: 「クリア。45 秒。ベストタイムを更新しました。N で新しいゲーム。」 |
| 敗北 | 「ゲームオーバー。地雷を開きました。N で新しいゲーム。」 |
| 新しいゲーム | 未開始と同じ |

- 勝利の文の色は緑（Green）、敗北の文の色は赤（Red）にする。色がなくても、文で分かる。
- 仕様書 5.2 の「勝利カードに当たるものは置かない」のとおり、勝利はこの行だけで知らせる。

### 3.6 キーの案内の行とヘルプ

キーの案内の行（76 升）:

```text
矢印/HJKL 移動  Space 開く  F 旗  N 新しいゲーム  D 難易度  ? ヘルプ  Q 終了
```

? キーで開くヘルプ（画面全体を置き換える）:

```text
キーの一覧

  矢印キー、H J K L   カーソルを動かす（H 左、J 下、K 上、L 右）
  Space、Enter        開く（数字のマスではコード）
  F                   旗を立てる・外す
  N                   新しいゲーム
  D                   難易度を選ぶ
  ?                   このキーの一覧
  Q、Ctrl+C           終わる

何かキーを押すと戻ります。
```

- ヘルプを開いている間も、経過時間は進む（仕様書 5.7）。ヘルプの画面には経過時間を出さない。

### 3.7 難易度の選択とカスタムの入力

D キーで開く画面（画面全体を置き換える）:

```text
難易度を選んでください

> 1  初級        9x9   地雷 10   ベスト  23 秒   （今の難易度）
  2  中級      16x16   地雷 40   ベスト  98 秒
  3  上級      30x16   地雷 99   記録なし
  4  カスタム

1〜4 のキー、または矢印と Enter で選びます。Esc で戻ります。
```

- 行の先頭の `>` は、矢印キーで動かす選択の位置である。開いたときは、今の難易度の行に置く。
- 今の難易度の行の末尾に「（今の難易度）」を付ける。Web 版 UI 2.3 のチェックの印に当たる。
- 数字のキー（1〜4）を押すと、その行をすぐに選ぶ。
- 初級・中級・上級を選ぶと、その難易度で新しいゲームを始めて、ゲームの画面に戻る（今と同じ難易度を選んだ場合も。Web 版 UI 8 章の決定 7）。

カスタムを選んだときは、同じ画面の下に 1 行ずつ尋ねる。

```text
カスタム（Enter だけで [ ] の中の値。Esc でやめる）
  幅（5〜30）[16]: 20
  高さ（5〜24）[16]: ２０
  地雷数（1〜391）[40]: 500
  1〜391 の整数を入力してください
  地雷数（1〜391）[40]: _
```

- 尋ねる行には、入力できる範囲と、今の盤面の値（`[ ]` の中）を示す。何も入れずに Enter を押すと、`[ ]` の中の値にする（Web 版 UI 8 章の決定 3 の「入力欄の初期値は、現在の盤面の値」に当たる）。
- 地雷数の範囲は、入力した幅と高さから求める（Web 版 UI 2.3）。
- 入力した文字列は、仕様書 3 章のとおり整えてから読む（上の例の全角の「２０」も 20 と読む）。
- 範囲の外や整数でないときは、次の行に「{min}〜{max} の整数を入力してください」（Web 版 UI 7 章と同じ文言）を出し、同じ値を尋ね直す。色を付けるときは赤にする。
- Esc を押すと、カスタムをやめて、前のゲームの画面に戻る（仕様書 5.7）。
- 3 つの値がそろったら、カスタムで新しいゲームを始めて、ゲームの画面に戻る。

### 3.8 端末が小さいとき

```text
端末の画面を広げてください。
このゲームには 76 列 x 30 行 が要ります（今は 80 列 x 24 行）。

D 難易度  Q 終了
```

- 3.2 の必要な大きさに足りないときは、盤面を描かず、この画面を出す（仕様書 5.5）。大きさの記号も、ASCII の `x` にする。
- 受け付けるのは D、Q、Ctrl+C だけである（仕様書 5.5）。
- 端末が広がったら、ゲームの画面に戻る。

### 3.9 色を付けないとき

- 環境変数 `NO_COLOR` が空でない値で設定されているときは、文字の色、背景の色、反転表示のどれも使わない（仕様書 5.6）。
- 記号（3.4）、角かっこのカーソル（3.4）、状態の行の文（3.5）で、すべての状態が分かる。

### 3.10 終わるとき

- Q か Ctrl+C で、代替画面を抜けて元の画面に戻り、カーソルを表示し、色を既定に戻す（仕様書 5.9）。終わった後の端末には何も出さない。

### 3.11 文言

| 場所 | 文言 |
|------|------|
| 上の行 | 初級、中級、上級、カスタム、{w}x{h}、残り地雷、経過時間、秒 |
| 状態の行 | マスを開くと始まります。、N で新しいゲーム。、（勝利・敗北の文は Web 版 UI 6.4 の読み上げの文） |
| キーの案内の行 | 3.6 のとおり |
| ヘルプ | 3.6 のとおり |
| 難易度の選択 | 難易度を選んでください、ベスト {n} 秒、記録なし、（今の難易度）、1〜4 のキー、または矢印と Enter で選びます。Esc で戻ります。 |
| カスタム | カスタム（Enter だけで [ ] の中の値。Esc でやめる）、幅、高さ、地雷数、{min}〜{max} の整数を入力してください |
| 端末が小さいとき | 端末の画面を広げてください。、このゲームには {w} 列 x {h} 行 が要ります（今は {w} 列 x {h} 行）。 |

- 文言には、幅があいまいな文字（×、※、①、■ など）を使わない（1.1）。全角の括弧（「（」「）」）とかぎ括弧は幅が 2 升と決まっているので使う。

## 4. 仕様書を補う決定

| # | 決定 | 理由 | 節 |
|---|------|------|----|
| 1 | デスクトップ版の既定のマスの大きさは 32px | 上級のウィンドウを 1366×768 の画面に収めるため | 2.2 |
| 2 | ウィンドウを最大化しているときに難易度を変えても、ウィンドウの大きさは変えない | 最大化は利用者が選んだ大きさで、それを崩さないため | 2.2 |
| 3 | 難易度ダイアログは、別のウィンドウにせず、ウィンドウの中に重ねる | ほかのウィンドウの後ろに隠れず、Web 版と見た目がそろう | 2.5 |
| 4 | デスクトップ版の書体は Yu Gothic UI（なければ Meiryo UI） | 日本語の字形を確実にするため（調査書 4.4） | 2.8 |
| 5 | デスクトップ版は、起動したときに盤面にキーボードのフォーカスを置く | すぐにキーボードで遊び始められる | 2.11 |
| 6 | コンソール版の未開放のマスは `#`、旗は `F`、地雷は `*`、踏んだ地雷は `@`、誤った旗は `X` | ASCII の文字で、形が互いに違い、旗はキーとそろう | 3.4 |
| 7 | コンソール版のカーソルは角かっこで示し、色があるときは反転表示も重ねる | 色がなくても分かるようにするため | 3.4 |
| 8 | コンソール版では、画面を端末の左上に置き、中央に寄せない | 端末の大きさが変わっても描く位置が変わらない | 3.1 |
| 9 | コンソール版のカスタムの入力で、何も入れずに Enter を押すと今の値にする | Web 版の入力欄の初期値（今の盤面の値）に当たる | 3.7 |
