# リリースノート

## 1.1.0（2026-09-27）

見た目を整え、効果音と、操作の結果を伝える動きを加えました。遊び方は 1.0.0 と同じです。1.0.0 で記録したベストタイムは、そのまま引き継ぎます。

- 公開先: https://fujiwo.github.io/Shos.Minesweeper/

### 効果音

- マスを開いたとき、まとめて開いたとき、旗を立てたとき・外したとき、負けたとき、勝ったときに、短い音が鳴ります。
- ツールバーのスピーカーのボタンで、音を消したり戻したりできます。この設定はブラウザーに記録し、次に開いたときも同じになります。
- iPhone では、本体の消音スイッチ（消音モード）に従います。
- ブラウザーの決まりで、音はページを開いてから最初に画面に触れたり、クリックやキーを押したりした後から鳴ります。

### 動き

- 0 のマスを開いて周りがまとめて開くときは、押したマスから外へ広がるように開きます。
- 負けたときは、踏んだ地雷がはじけ、ほかの地雷が近い順に現れます。勝ったときは、旗が近い順に跳ねます。
- 動きの間も、すぐに次の操作ができます。
- OS で動きを減らす設定をしていると、これらの動きと、ボタンを押したときの縮みを止めます。

### 見た目

- 盤面を 1 枚の板にし、開いていないマスを、角の丸いタイルにしました。
- ツールバーを 1 本の帯にまとめ、ボタンの形をそろえました。押している間は、ボタンが少し縮みます。
- ツールバーを盤面のすぐ上に付け、盤面とまとめて画面の縦の中央に置きます（スマートフォンの横向きでは、1.0.0 と同じく、ツールバーを盤面の左に置きます）。
- 勝ったときのカードを小さくし、盤面の下に余白があれば、盤面に重ねずに置きます。

### 入力

- カスタムの幅・高さ・地雷数に、全角の数字（「２０」など）や、前後の空白が入っていても、そのまま始められます。

### 知っておいてほしいこと

- 効果音の設定も、ベストタイムと同じく、使っているブラウザーの中にだけ記録します。
- ページを開いて最初の操作のときだけ、ブラウザーが音を鳴らす準備をするため、音（とマスが開く表示）が 0.1〜0.2 秒ほど遅れることがあります。2 回目からは遅れません。
- タッチの端末で、ページを開いて最初の操作が長押しで旗を立てたときは、その旗の音だけ鳴りません（まだ音を鳴らせる状態になっていないため）。2 回目の操作からは鳴ります。
- 動作環境は 1.0.0 と同じです。

## 1.0.0（2026-09-26）

ブラウザーで遊べるマインスイーパーの最初の版です。スマートフォン、タブレット、PC のブラウザーで遊べます。

- 公開先: https://fujiwo.github.io/Shos.Minesweeper/
- インストールは要りません。最初に開いたときに、アプリ（約 3.6MB）を読み込みます。

### 遊べること

- 難易度: 初級（9×9、地雷 10）、中級（16×16、地雷 40）、上級（30×16、地雷 99）、カスタム（幅 5〜30、高さ 5〜24、地雷 1〜「幅×高さ − 9」）
- 最初に開いたマスとその周りには、地雷がありません。最初の一手で負けることはありません。
- 開いた数字のマスを押すと、周りの旗の数が数字と同じときに、残りのマスをまとめて開きます（コード）。
- 初級・中級・上級のベストタイムを、ブラウザーに記録します。

### 操作

| 操作 | マウス | タッチ | キーボード |
|------|--------|--------|------------|
| マスを開く | 左クリック | タップ | 矢印キーでマスを選び、Space か Enter |
| 旗を立てる・外す | 右クリック | 長押し（400 ミリ秒。円が満ちたら旗） | F |
| まとめて開く（コード） | 開いた数字のマスを左クリック | 開いた数字のマスをタップ | 開いた数字のマスで Space か Enter |

- ツールバーの旗モードのボタンを押すと、タップ（マウスでは左クリック）で旗、長押しで開く、に入れ替わります。スマートフォンで旗を続けて立てるときに便利です。
- 顔のボタンで新しいゲームを始め、難易度のボタンで難易度を変えます。

### 画面

- 画面の大きさと向きに合わせてマスの大きさを決めます。縦と横を入れ替えたほうがマスを大きくできるときは、盤面を入れ替えて表示します。プレイ中に画面の向きを変えても、ゲームはそのまま続きます。
- OS のライトとダークの設定に合わせた配色になります。
- OS で動きを減らす設定をしていると、旗と勝利の表示のアニメーションを止めます。
- スクリーンリーダーで、マスの位置と状態、新しいゲーム、勝敗を読み上げます。

### 動作環境

各 OS の最新版の Chrome、Edge、Safari、Firefox。iOS と iPadOS では、どのブラウザーでも同じように動きます。

### 知っておいてほしいこと

- ベストタイムは、使っているブラウザーの中にだけ記録します。別の端末や別のブラウザーとは共有しません。プライベートブラウズなど、記録できない環境でも遊べますが、ベストタイムはページを閉じると消えます。
- 長押しで旗が立ったときの振動は、振動に対応した端末とブラウザー（Android の Chrome など）だけです。iPhone では振動しません。
- ブラウザーのタブのアイコンは SVG です。SVG のアイコンに対応していないブラウザーでは、ブラウザーの既定のアイコンになります。
- オフラインでは遊べません（ページを開くときに、インターネットにつながっている必要があります）。
- 画面の言語は日本語だけです。

### この版にないもの

？マーク、左右同時クリックと中クリックでのコード、地雷の位置を推測しなくて済む盤面（No Guessing）、プレイ回数や勝率の統計、オフライン対応。
